# 🔍 gaps-Sites

مدقق ثغرات المواقع الاحترافي – أداة تدقيق أمني متقدمة لكشف 15+ نوع من الثغرات في تطبيقات الويب.

---

## 📖 نبذة

**gaps-Sites** هي أداة تدقيق أمني (Security Auditor) لتطبيقات الويب، مصممة لكشف واستغلال أكثر من 15 نوعاً من الثغرات الأمنية الشائعة. تم تطويرها للأغراض التعليمية واختبار الاختراق الأخلاقي.

---

## 🔥 المميزات

- **كشف تلقائي للصفحات والمعاملات** (Crawling)
- **اختبار 15+ نوع ثغرة أمنية**
- **استغلال تلقائي للثغرات المكتشفة**
- **تقرير مفصل بصيغة JSON**
- **دعم متعدد الخيوط** (Multithreading) للسرعة
- **واجهة سطر أوامر ملونة وسهلة الاستخدام**

---

## 🛡️ أنواع الثغرات المدعومة

| # | الثغرة | الوصف |
|---|--------|-------|
| 1 | SQL Injection | حقن أوامر SQL في قاعدة البيانات |
| 2 | XSS | البرمجة النصية عبر المواقع |
| 3 | LFI | تضمين الملفات المحلية |
| 4 | RFI | تضمين الملفات البعيدة |
| 5 | RCE | تنفيذ الأوامر عن بُعد |
| 6 | SSTI | حقن قوالب الخادم |
| 7 | XXE | حقن الكيانات الخارجية XML |
| 8 | SSRF | تزوير الطلبات من جانب الخادم |
| 9 | CSRF | تزوير الطلبات عبر المواقع |
| 10 | NoSQL Injection | حقن NoSQL |
| 11 | LDAP Injection | حقن LDAP |
| 12 | Command Injection | حقن الأوامر |
| 13 | Open Redirect | إعادة التوجيه المفتوحة |
| 14 | File Upload | رفع الملفات الخبيثة |
| 15 | Admin Panel | كشف لوحات الإدارة المخفية |
